# Bomberman – MASM Assembly Game

## Project Overview

This project is a Bomberman-inspired game developed using **x86 Assembly (MASM)** and the **Irvine32 library**. The game runs in the Windows console (on Visual Studio)


## Controls

| Key | Action |
|---|---|
| W | Move up |
| A | Move left |
| S | Move down |
| D | Move right |
| E | Place a bomb |
| W / A / S / D | Select bomb placement direction |
| R | Restart after winning or losing |
| Q | Quit after winning or losing |

## How to Play

1. Start a new game to generate a random map.
2. Navigate through the map using WASD and your helpful BOMBS.
3. Place bombs next to destructible blocks to clear paths.
4. Bombs explode after two successful movements.
5. Find and destroy the secret block to reveal the hidden exit.
6. Move onto the exit to complete the level.
7. Avoid getting caught in an explosion, or the game will end.

## Requirements and Dependencies

The project requires:

- Windows operating system
- Visual Studio (and a working version at that)
- MASM x86 assembler
- Irvine32 library

## Compilation and Running Instructions

1. Clone or download the project repository from GitHub.
2. Open the Visual Studio solution (`.sln`) file.
3. Build Solution.
4. If building the solution doesn't work, make sure you exclude any files that are not .asm or .inc (but only after trying to build).
5. Pray that the solution is built.
6. If the solution is built, I suggest using Ctrl + F5 to play (or just build again)
7. Have fun!
